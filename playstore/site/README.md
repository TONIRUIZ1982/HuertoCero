# Web minima para Google Play

Esta carpeta contiene una web estatica lista para publicar en cualquier hosting simple:

- `index.html`
- `privacy.html`
- `delete-account.html`
- `styles.css`

Cuando tengas dominio o hosting, sube estos archivos y usa estas URLs en Play Console:

- Politica de privacidad: `https://TU-DOMINIO/privacy.html`
- Borrado de cuenta: `https://TU-DOMINIO/delete-account.html`

Antes de publicar, cambia `soporte@huertocero.com` por el correo real de soporte.
